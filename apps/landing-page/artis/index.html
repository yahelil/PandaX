Our product

Artis

The product. A release goes in, a reviewable record comes out.

Artis is built by PandaX. It reads an SBOM, matches it against public advisory sources, records what you decide about each finding, generates the documents, and seals the result to the release that shipped.

What it does

artis
  1. › ingest release-4.2.1 412 components
  2. › match osv · kev · epss 7 findings
  3. › assess reachability 1 needs a decision
  4. › record decision + rationale logged
  5. › docs annex vii · annex v generated
  6. › seal ed25519 sealed
  7. ›

One command. The record is the output, not a by-product.

FindingsEach with the upgrade that clears it.

What exists today

Working today

  • Ingest a release and build the component inventory.
  • Match against public advisory sources, with failed sources shown as failed.
  • Record decisions with their rationale, author and date.
  • Generate the documents and seal the result.
  • Verify a sealed bundle from a clean machine, with a key supplied separately.

Being built

  • The hosted workspace, for more than one person.
  • Connectors into Jira, CI/CD and document systems.
  • Scheduled advisory monitoring that opens cases on its own.
